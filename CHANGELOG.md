# Changelog

## 0.1.0 — Experimental release

- Separate Home Assistant sidebar dashboard and reusable Lovelace card.
- Polish and English, automatic HA-language selection and per-user view preferences.
- Registry-based multi-appliance discovery, honoring read/control permissions.
- Cooktop and dishwasher layouts plus generic cards for other reported readings.
- Native, already-enabled dishwasher program select; no synthesized appliance controls.
- Reported messages, source-provided cleaning reminders and TLS expiry diagnostics.
- Responsive light/dark layouts, unknown-state handling and reconnect safeguards.

Companion to ThingsLocal Bridge, continued work on LocalThings by purplesym (Lars).
